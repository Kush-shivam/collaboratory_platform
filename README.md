PROJECT DETAILS ->
1: A COLLABORATORY PLATFORM, WHERE MULTIPLE LOGIN BASED USERS CAN COLLABORATE JUST LIKE GIT HUB.
2: RATHER THAN JUST EDITING CODES AND FILES TOGETHER, HERE USERS CAN EDIT IMAGES, VIDEOS, PDF, CANVA AND CODES.
3: ALSO RATHER THAN MAKING DUPLICATE REPOSITORIES, HERE ALL USERS WILL HAVE DEDICATED ACCESS TO SAME DATABASE USING PROPER ALGORITHM TO AVOID DEADLOCK.
4: IT WILL BE TOTALLY ONLINE PLATFORM AND LIVE TIME EDITING WILL BE VISIBLE TO OTHER USERS, AND WILL BE SAVED TO REVERT THE MISTAKES.
5: EXTRA FEATURES FOR FUTURE CONTEXT : A-> AI ML AND PROMPT BASED EDITING.
                                      B-> A SECURE PLATFORM DEPENDENCY AND TOKENIZED ROUTING.
                                      C-> DATA PREPARATION FOR USER FRIENDY ENVIRONMENT AND PROMPTING.
CODES AND SETUPS: 
1-> FRONTEND:- EDITING SOFTWARE EMBEDDED WITH HTML AND NEXT.JS OR REACT. LIKE MONOCO, FABRIC.JS
2-> CONTROLING LOCKING ALGORITHM:- WEBSOCKET(SOCKET.IO) AND REST APIs
3-> BACKEND:- USING NODE.JS OR RESPECTIVE LANGUAGES LIKE EXPRESS.JS TO MANAGE AUTHENTICATION, LOCKING AND API ROUTES.
4-> DATABASE:- a. USING POSTGRESQL TO STORE USER PERMISSION AND PROJECT DATA,
               b. USING REDIS TO STORE WEBSOCKET DATA.
               c. USING ONLINE SERVICES LIKE AWS OR CLOUD TO STORE IMAGE, VIDEO, PDF, CANVA ETC FILES.
